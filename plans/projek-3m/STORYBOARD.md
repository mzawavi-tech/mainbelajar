# STORYBOARD: Demo Program 3 Bulan 3M — MainBelajar Awang & Melur

- **Tujuan video:** demo produk/program untuk ibu bapa; tunjuk kalendar, tugasan, gameplay dan bukti kemajuan tanpa menjanjikan hasil.
- **Platform & nisbah:** 16:9 laman web / YouTube; potongan 9:16 boleh dibuat selepas suntingan utama.
- **Tempoh sasaran:** 75–90 saat
- **Gaya:** animasi 3D lembut, warna cerah, suasana Malaysia, Awang & Melur konsisten dengan character sheet rasmi; UI dashboard bersih.
- **Bahasa suara:** Bahasa Melayu

## Peraturan
- Teks skrin lurus, besar, mudah dibaca.
- Jangan dakwa hasil belajar yang tak dapat dibuktikan (contoh “anak pasti pandai”).
- Jangan tunjuk wajah kanak-kanak sebenar tanpa kebenaran ibu bapa.
- Skor yang dipaparkan dalam video demo mesti data demo berlabel “contoh”, bukan keputusan pelanggan sebenar.
- UI yang dijana video ialah visual konsep; rakaman skrin produk sebenar perlu menggantikan UI rekaan sebelum video diterbitkan.
- Jangan masukkan harga atau perkataan “langganan” sehingga model harga diputuskan Awie.

## Aset sedia ada
- Watak Awang dan Melur: character sheet rasmi projek.
- Aktiviti membaca: halaman game Baca dengan huruf, suku kata, susun perkataan dan baca/pilih.
- Aktiviti mengira: halaman game Kira dengan nombor, membilang objek dan perbandingan; modul penuh perlu disemak sebelum rakaman.
- Aktiviti melukis: Lukis Ajaib mempunyai kanvas bebas; ia belum menjadi latihan tulisan berstruktur.
- Tema empat dunia ialah arah seni program; kewujudan sebagai dunia game lengkap perlu disahkan/dibina.
- Logo MainBelajar dan rakaman dashboard sebenar perlu disediakan selepas UI siap.
